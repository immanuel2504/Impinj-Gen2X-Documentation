Impinj TagFocus instructs tags that have already been inventoried to remain unresponsive, allowing the reader to focus on new or unread tags. By keeping already-read tags silent, the reader has a far greater chance of finding difficult-to-read tags in dense environments. TagFocus is a reader-scoped feature that targets tags inventoried in session S1. The reader inventories tags in session S1 automatically when TagFocus is enabled; you do not need to set the session explicitly.
